# Capstone Project Policy

## 1. What the capstone is

The capstone is a team project in which you build and evaluate a retrieval-augmented generation (RAG) system on a real document collection. It is worth 40% of the final grade.

## 2. Deadline and late work

The capstone is due on 14 December at 23:59 (local time), submitted through the course portal. Late work loses 10% of the capstone grade per day, for up to 3 days. Work submitted more than 3 days late is not graded.

## 3. Extensions

Extensions must be requested before the deadline using form EXT-7. Extensions are granted for documented illness or emergencies only, and never for more than 7 days.

## 4. What to hand in

Submit the code repository link, a 4-page report, and a 5-minute demo video. The report must include an evaluation table with at least 10 test questions.
